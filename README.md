# 🏋️ NexFit — Modern Fitness & Class Management Platform

**NexFit** is a full-stack, high-performance fitness web application built with **Next.js 15 (App Router)**, **Tailwind CSS**, and **Better Auth**. Designed with a dark glassmorphism aesthetic, it offers gym members and trainers an intuitive dashboard to manage class bookings, track workout stats, and handle trainer applications.

---

## ✨ Features

- **🔐 Authentication & Session Management**: Built using `Better Auth` for secure authentication and session persistence.
- **📊 Interactive Member Dashboard**:
  - **Overview**: Real-time stats on booked classes, favorite workouts, and application statuses.
  - **Booked Classes**: View and manage upcoming fitness sessions.
  - **Favorites**: Quick access to saved workout classes.
  - **Trainer Application Workflow**: Apply to become a trainer with real-time application status tracking (`Pending`, `Approved`, `Rejected` with custom feedback).
- **📱 Fully Responsive Design**: Built with a mobile-first approach featuring slide-out drawers, backdrop overlays, and smooth desktop-to-mobile transitions.
- **🎨 Glassmorphism & Modern UI**: High-contrast dark theme with glowing neon accents (`#f97316`) powered by Tailwind CSS.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router & Client Components)
- **Library**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [React Icons](https://react-icons.github.io/react-icons/) (`fi`, `fa`)
- **Authentication**: `Better Auth`
- **Backend API**: Express.js / Node.js (REST API integration)
